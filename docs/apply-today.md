# Apply Today

Run `supabase/migrations/202611030001_apply_today.sql` in the same Supabase project used by the dashboard. Then open **Engagement → Apply Today** in live mode.

The New projects filter shows up to 250 recent Job Platforms discovery records. Open the original post and confirm it is still open before shortlisting. Add the client's requirement, your fit and a portfolio URL, then write a proposal or start from the provided draft. Submit on the original platform and record the result in the dashboard.

Application progress is separate from lead approval and email outreach. The feature does not trigger n8n or send anything. Application notes and stages are shared within the authenticated dashboard.
